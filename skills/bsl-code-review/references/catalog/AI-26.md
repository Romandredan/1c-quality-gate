## Триггер

Повторная отправка после «неизвестного исхода» (таймаут, неразобранный ответ) без сверки фактического состояния операции с сервисом.

## Почему

«Неизвестный исход» означает: запрос мог уйти и исполниться — ответ просто не вернулся или не разобрался. Повторная отправка в этом состоянии выполняет операцию второй раз: второй возврат денежных средств, второе создание объекта. Это принципиально отличается от определённого отказа: при отказе сервиса повтор безопасен, при неизвестном исходе — нет, и обращаться с ними одинаково (просто вернуть в «Новый») — ошибка.

Коварство в том, что ветки в коде рядом: отказ и неизвестный исход фиксируются соседними строками, и обработчик повтора, закрытый от «выполнено», пропускает «неизвестно» на общих основаниях.

Реальный случай: повтор записи очереди возвратов после комментария «Неизвестный исход обращения» возвращал запись в состояние «Новый» без обращения к сервису или буферу загрузки — при том что ветка «возврат уже выполнен сервисом» в той же процедуре существовала.

## Как чинить

- Перед повтором после неизвестного исхода — сверка: запрос статуса операции у сервиса либо поиск выполненной операции в буфере загрузки/журнале транзакций.
- Сверка недоступна — запись блокируется от повтора (неустранимая ошибка, ручной разбор), а не возвращается в работу.
- В классификации исходов держать три ветки, а не две: «отказ» (повтор разрешён), «выполнено» (повтор запрещён), «неизвестно» (повтор только после сверки).
- Идемпотентность операции на стороне сервиса (по ключу операции) снимает риск — тогда фиксировать её в комментарии у повторной отправки.

#### Неправильно

```bsl
Если СтрНайти(Запись.Комментарий, ТекстВозвратВыполненСервисом()) > 0 Тогда
    Возврат ОтразитьИзБуфера(Запись);  // сверка есть только для «выполнено»
КонецЕсли;
Запись.Состояние = СостоянияОчереди.Новый;  // «неизвестный исход» проходит сюда
Запись.КолПопыток = 0;
```

#### Правильно

```bsl
Если ИсходНеизвестен(Запись.Комментарий) Тогда
    НайденныйВозврат = НайтиВыполненнуюОперациюВБуфере(Запись);
    Если НайденныйВозврат = Неопределено Тогда
        Возврат НСтр("ru = 'Исход предыдущей отправки неизвестен: повтор доступен после сверки с сервисом.'");
    КонецЕсли;
КонецЕсли;
```

## Когда это не дефект

- Операция идемпотентна на стороне сервиса — повтор заявлен контрактом API безопасным.
- Сверка уже выполняется в самой команде повтора до отправки.
- Исход классифицирован как определённый отказ сервиса.
