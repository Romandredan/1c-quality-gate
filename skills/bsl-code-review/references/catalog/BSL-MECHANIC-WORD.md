## Триггер

Имя в изменённом методе содержит слово механики из списка проекта.

## Почему

Имя из предметной области говорит, что лежит в значении. Имя механики — «Кандидаты», «Снимок»,
«Прочие» — говорит только, на каком шаге алгоритма значение появилось, и читателю приходится
восстанавливать смысл по коду. Если имя из предметной области не подбирается, метод обычно
собирает несвязанные вещи, и его надо резать иначе.

## Как чинить

#### Неправильно

```bsl
Кандидаты = ЗаписиКВыпуску();
НачалоОкна = НачалоОкнаСбора();
```

#### Правильно

```bsl
НевыпущенныеСтрокиЗаказов = ЗаписиКВыпуску();
НачалоПериода = НачалоПериодаСбора();
```

Термины учёта в 1С своими не подменяются: граница отбора по дате — период, а не «окно».

## Когда это не дефект

- слово из списка — часть предметного термина: «прочие расходы», «окно формы» в коде
  интерфейса. Список проекта составляется из начал слов, которые в этом проекте означают только
  механику, и поэтому находка — подсказка, а не предупреждение;
- имя пришло из типового кода или внешнего протокола, и переименование разорвало бы связь с
  источником.

## Что проверяет инструмент

Проверка: `qg:BSL-MECHANIC-WORD` (`tools/bsl-lint.mjs`), 🟡, подсказкой — в изменённом
методе имя метода, параметра, переменной, переменной цикла, псевдонима или параметра запроса
содержит слово из списка проекта. Запись списка — начало слова внутри имени: `Окн` находит
`НачалоОкнаСбора`. У плагина своего списка нет: пустой список выключает правило, и в след
уходит пропуск с причиной `not_applicable`.

**Чего не ловит.** Главное в правиле — «не подбирается имя, значит метод режется иначе» —
механически не выражается: инструмент ловит только известные слова.
