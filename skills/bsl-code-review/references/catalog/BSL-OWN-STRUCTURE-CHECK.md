## Триггер

`Свойство(Имя)` в цикле по `СтрРазделить` со списком обязательных полей структуры.

## Почему

Метод принимает структуру и первым делом проверяет, что в ней есть все поля из списка. Если
структуру создаёт собственный конструктор модуля, её состав задан кодом: поля не может не
быть. Проверка выдаёт обязательное за необязательное, а опечатку в имени поля прячет под
штатной веткой — вместо ошибки в месте опечатки приходит отказ с текстом «нет поля».

## Как чинить

#### Неправильно

```bsl
Для Каждого ИмяПоля Из СтрРазделить("Идентификатор,Операция,Основание,Склад", ",") Цикл
    Если Не Параметры.Свойство(ИмяПоля) Тогда
        ВызватьИсключение СтрШаблон(НСтр("ru = 'Нет поля %1'"), ИмяПоля);
    КонецЕсли;
КонецЦикла;
```

#### Правильно

```bsl
// Параметры создаёт ПараметрыПостановки() этого модуля: состав задан кодом.
Если Не ЗначениеЗаполнено(Параметры.Идентификатор) Тогда
    ВызватьИсключение НСтр("ru = 'Не заполнен идентификатор'");
КонецЕсли;
```

Проверка заполненности значений остаётся, если запись может прийти не из кода — например,
поставлена оператором вручную. Уходит только проверка состава.

## Когда это не дефект

- структура пришла из внешнего источника — разобранный JSON, параметры другой подсистемы,
  настройка пользователя: её состав код не гарантирует;
- метод — программный интерфейс, который вызывают из других подсистем с собственными
  структурами, и конструктор модуля не единственный способ её получить.

## Что проверяет инструмент

Проверка: `qg:BSL-OWN-STRUCTURE-CHECK` (`tools/bsl-lint.mjs`), 🟡, только вопросом —
`Для Каждого <Имя> Из СтрРазделить(<литерал или переменная с литералом>, …) Цикл`, и в теле
цикла `<Структура>.Свойство(<Имя>)`. Откуда пришла структура, инструмент не знает, поэтому
утверждать дефект не может: ответ на вопрос — источник структуры. Проверку наличия реквизитов
по метаданным разбирает `qg:AI-19`.

**Чего не ловит.** Проверку, записанную цепочкой `Если Не С.Свойство("А") Или Не
С.Свойство("Б")` без цикла, и список полей, собранный не литералом.
