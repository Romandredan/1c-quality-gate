# Индекс триггеров каталога антипаттернов

Производный файл — источник истины карточки `catalog/<ID>.md`. Правки вносить в карточки,
индекс перегенерировать: `node tools/gen-catalog-index.mjs`.

Здесь только то, что нужно для обнаружения: идентификатор, важность и триггер. Разбор,
способ исправления и законные формы — в карточке; она читается по попаданию, а не заранее.
Карточки с инструментом перечислены ради «как чинить»: их находки печатает инструмент,
своих находок этого класса не добавляй.

Часть уроков из того же источника относится не к коду, а к устройству программы, и живёт
в контуре `bsl-architecture-review`: доверие результату собственной функции, одна граница
проверки вместо повторных, общий механизм вместо копии функции на каждый вариант входа,
вынесение подготовки данных в отдельный метод, поле под будущий признак в самой записи,
функция-конструктор для структуры, которая уходит наружу.

Регистрация объекта метаданных в составе конфигурации проверяется контуром
`xml-structure-review`: файл на диске, не внесённый в состав, не попадает в сборку, при
этом ни загрузка конфигурации, ни валидаторы структуры этого не диагностируют.
