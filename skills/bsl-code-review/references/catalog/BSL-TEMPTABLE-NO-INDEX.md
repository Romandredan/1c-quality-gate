## Триггер

`ПОМЕСТИТЬ ВТ...` без `ИНДЕКСИРОВАТЬ ПО`, а таблица дальше участвует в соединении.

## Почему

Влияние: соединение по неиндексированному полю временной таблицы даёт полный перебор её строк
на каждую строку второго источника. На больших выборках это основная причина того, что «запрос
без единой ошибки работает минуты».

## Как чинить

Добавить `ИНДЕКСИРОВАТЬ ПО` по полю, задействованному в соединении.

#### Неправильно

```sql
-- HIGH: ВТ соединяется по Номенклатура, но индекса нет
ВЫБРАТЬ Номенклатура, Количество ПОМЕСТИТЬ ВТОстатки ИЗ ...
```

#### Правильно

```sql
ВЫБРАТЬ Номенклатура, Количество ПОМЕСТИТЬ ВТОстатки ИЗ ...
ИНДЕКСИРОВАТЬ ПО Номенклатура
```

## Когда это не дефект

- временная таблица до 100 строк;
- таблица, которая далее не участвует в соединении;
- таблица заведомо мала (десятки строк) либо используется однократно без соединений —
  построение индекса тогда дороже выигрыша.

## Что проверяет инструмент

Ничего: текст запроса — строковый литерал, разбор доступен только чтением.
