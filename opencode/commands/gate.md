Прогони контроль качества по текущим изменениям.

Загрузи скил через инструмент `skill` — skill({ name: "quality-gate" }) — и следуй ему полностью:

1. Определи профиль изменения по трём осям — объём, архетипы кода, сложность. Пороги возьми
   из `tools/config.mjs show`, оттуда же перенеси строку `config=...` в запись `scope`.
2. Выбери глубину каждого контура по матрице.
3. Прогони только нужные контуры; непрогнанные зафиксируй записью `skipped` с причиной.
4. Проверь живость источника стандартов (sentinel).
5. Сформируй отчёт с находками и секцией `## quality evidence`.
6. Сними гейт через `tools/gate.mjs release --evidence <файл отчёта>`.

Аргументы (если переданы): $ARGUMENTS

- `--deep` — поднять глубину на ступень против расчётной
- `--quick` — минимальный прогон; допустимо только для класса C0/C1
- `--fix` — применить безопасные исправления (именование, форматирование, quick-fix);
  логику, запросы, транзакции и права не трогать без подтверждения
