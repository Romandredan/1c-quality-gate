## Триггер

Запись очереди без поля, которое читает другой контур (дата постановки → сигнал застревания), при заполнении его остальными продюсерами очереди.

## Почему

Реквизит записи очереди — контракт между продюсерами и потребителями. Дата постановки — не деталь реализации: сигнал «ждёт дольше порога» в карточке заказа опирается на неё, и при пустой дате условие `ЗначениеЗаполнено(ДатаПостановки)` просто не срабатывает — зависшая команда становится невидимой для мониторинга. Ошибка не ловится ни тестами продюсера (он про дату не знает), ни потребителем (тот честно проверяет заполненность).

Механическая ловушка: `ЗаполнитьЗначенияСвойств` не переносит незаполненные значения источника. Структура-конструктор, вернувшая поле даты без значения, оставит реквизит записи пустым, даже если поле перечислено в списке переносимых свойств.

Реальный случай: новый сборщик заказов передавал структуре постановки значения из конструктора по умолчанию (дата не заполнена), при этом все три существующих продюсера той же очереди дату проставляли явно после конструктора.

## Как чинить

- Новый продюсер очереди сверяет набор заполняемых полей со всеми существующими продюсерами этой очереди перед написанием кода, а не после ревью.
- Поля, обязательные по смыслу (дата постановки, приоритет, режим), проставляются явно после конструктора структуры: `Структура.ДатаСоздания = ТекущаяДатаСеанса();`.
- Если поле должно заполняться всегда — надёжнее заполнять его в самой процедуре постановки, а не доверять каждому продюсеру.

#### Неправильно

```bsl
// Дата из конструктора не заполнена, ЗаполнитьЗначенияСвойств её не перенесёт
ОчередьОтправки.ПоставитьОбъектВОчередь(Заказ, Операция, УчетнаяЗапись,
    ОчередьОтправки.СтруктураРеквизитовЗаписи());
```

#### Правильно

```bsl
Структура = ОчередьОтправки.СтруктураРеквизитовЗаписи();
Структура.ДатаСоздания = ТекущаяДатаСеанса();
ОчередьОтправки.ПоставитьОбъектВОчередь(Заказ, Операция, УчетнаяЗапись, Структура);
```

## Когда это не дефект

- Поле заполняется внутри вызываемой процедуры постановки — продюсер передаёт только отличия от умолчаний.
- Потребителей поля нет, либо потребитель читает его с запасным вариантом (другое поле, текущая дата).
- Очередь — одноразовый буфер без внешних потребителей.

## Что проверяет инструмент

Ничего.
